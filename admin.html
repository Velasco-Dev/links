Pasos para Activar tu Enlace Publico en GitHub Pages

Para que tus enlaces comiencen a redirigir desde cualquier telefono del mundo en tu repositorio https://github.com/Velasco-Dev/links, solo requieres dos acciones sencillas:

  1. Subir los archivos de esta carpeta a tu repositorio `links`:
    Abre una terminal en G:\Ingenieria Informatica\Git Externo\links y ejecuta: 
    git init
git remote add origin https://github.com/Velasco-Dev/links.git
git add .
git commit -m "Inicializar suite de enlaces NOX y redirecciones"
git branch -M main
git push -u origin main
  2. Activar GitHub Pages en el repositorio:
    1. Ve a tu repositorio en GitHub: https://github.com/Velasco-Dev/links
    2. Haz clic en la pestaña Settings (Configuracion).
    3. En el menu izquierdo, haz clic en Pages.
    4. En la seccion Build and deployment > Branch, selecciona la rama main y carpeta / (root).
    5. Haz clic en Save.
  3. Listo: En menos de 60 segundos tu sitio estara activo en:
    https://velasco-dev.github.io/links/
