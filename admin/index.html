¿Por que no se actualizan los cambios automaticamente? GitHub Pages es un alojamiento estatico (sin backend ni base de datos activa). Cuando editas un enlace en el navegador, el cambio solo se guarda en la memoria de tu dispositivo (localStorage).
Para que cualquier edicion que hagas desde tu telefono o computadora se guarde de verdad en el repositorio y se publique en tiempo real sin necesidad de abrir la terminal, ingresa tu GitHub Personal Access Token (PAT) a continuacion:

El token se guarda unicamente en el almacenamiento privado de tu navegador. Jamas se sube al repositorio ni se expone publicamente.
